앱 설치 방법

SiteOps Checklist는 앱 스토어 없이 브라우저에서 바로 설치합니다. 무료이고, 설치 파일을 받지 않습니다.

이 브라우저에서는 바로 설치할 수 있습니다.

이미 앱으로 실행 중입니다.

📱 아이폰·아이패드 (Safari)

  1. Safari로 siteops-checklist.vercel.app을 엽니다.
  2. 아래(아이패드는 위)의 공유 버튼(네모에 위쪽 화살표)을 누릅니다. 안 보이면 ⋯ 메뉴 안에 있습니다.
  3. 목록을 내려 홈 화면에 추가를 누릅니다.
  4. 오른쪽 위 추가를 누르면 홈 화면에 아이콘이 생깁니다.

아이폰의 Chrome에서도 공유 버튼 → 홈 화면에 추가로 설치할 수 있지만, Safari를 권장합니다.

🤖 안드로이드 (Chrome)

  1. Chrome으로 사이트를 엽니다.
  2. 화면 아래 설치 안내가 뜨면 누릅니다. 안 뜨면 오른쪽 위 ⋮ 메뉴 → 앱 설치(또는 홈 화면에 추가)를 누릅니다.
  3. 설치를 누르면 앱 서랍과 홈 화면에 아이콘이 생깁니다.

삼성 인터넷: 아래 메뉴(≡)에서 홈 화면에 추가를 누릅니다.

🪟 윈도우 (Edge · Chrome)

  1. Edge: 주소창 오른쪽의 앱 설치 아이콘을 누르거나, 오른쪽 위 ⋯ → 앱 → 이 사이트를 앱으로 설치를 누릅니다.
  2. Chrome: 주소창 오른쪽의 설치 아이콘(모니터에 아래 화살표)을 누르거나, 오른쪽 위 ⋮ → 전송, 저장, 공유 → 앱 설치를 누릅니다.
  3. 설치를 누르면 시작 메뉴에 추가되고, 작업 표시줄에 고정할 수 있습니다.

🍎 맥 (Chrome · Safari)

  1. Chrome: 주소창 오른쪽 설치 아이콘, 또는 ⋮ → 전송, 저장, 공유 → 앱 설치. 응용 프로그램 폴더와 Launchpad에 추가됩니다.
  2. Safari(macOS Sonoma 이상): 메뉴 막대의 파일 → Dock에 추가를 누릅니다.

설치 후

  • 처음 열면 Google로 로그인합니다. 처음 로그인하면 자동으로 가입되고, 예시 점검 항목이 들어 있습니다.
  • 앱 내용은 항상 최신 버전으로 자동 업데이트됩니다.
  • 삭제하려면 다른 앱처럼 아이콘을 길게 눌러(휴대폰) 삭제하거나, 앱 창의 ⋮ 메뉴에서 제거(PC)를 누릅니다. 앱을 지워도 계정과 데이터는 남아 있습니다. 데이터까지 지우려면 앱 아래의 서비스 탈퇴를 이용해 주세요.
