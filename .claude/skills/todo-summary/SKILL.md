# 오늘 완료 요약

1. `node cli.js summary`를 실행한다. 데이터는 이 명령으로만 읽는다 (DB 파일을 직접 열지 않는다).
2. 출력을 그대로 보여 준다.
3. 이어서 커밋 메시지 형식으로 정리한다:

```
오늘 완료 <N>건 (<YYYY-MM-DD>)

- <완료한 항목>
- <완료한 항목>

남은 할 일 <N>건, 기한 지남 <N>건
```

- 오늘 완료가 0건이면 "오늘 완료한 항목이 없습니다."라고만 말한다.
- 실제로 `git commit`을 하지는 않는다. 메시지만 보여 준다.
